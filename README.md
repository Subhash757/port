## 📌 About

**RESUME-PORT** is a personal resume portfolio website designed to present my skills, projects, and background in a clean, responsive, and professional format. Built with pure HTML, CSS, and JavaScript — no frameworks, just clean code.

---

## ✨ Features

- 📄 Resume-style layout with sections for Skills, Projects, Education & Contact
- 📱 Fully responsive — works on mobile, tablet, and desktop
- ⚡ Fast load, no dependencies
- 🎨 Clean dark/light themed UI
- 🔗 Direct links to GitHub projects and profiles

---

## 🗂️ Sections

| Section | Content |
|---|---|
| 👤 About | Introduction and summary |
| 🛠️ Skills | Tech stack and tools |
| 🚀 Projects | Featured GitHub projects |
| 🎓 Education | Academic background |
| 📬 Contact | Email and social links |
